# Changelog

All notable changes to **Mahi UI Component Playground** will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/), and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.0.0] - 2026-10-09

### Added
- **7 Core Interactive Component Suites**: Buttons, Badges, Cards & Bento Grid, Tooltips, Modals, Tabs, and Action Dropdowns.
- **Three.js 3D Spatial Geometry Lab**: Client-side WebGL canvas with geometry switching (Torus Knot, Cube, Sphere, Cone), lighting controls, wireframe mode, and React Three Fiber (R3F) code exporter.
- **Curated Catalog of 459 Resources**: Searchable and categorized directory of design inspiration, AI tools, animation libraries, and developer utilities with zero duplicate links.
- **30 Frontend Developer Projects**: Roadmap inspired by Cult UI, Forge UI, 21st.dev, Magic UI, and Evil Charts with 29 embedded interactive modules.
- **Design System Tokens & Ramp Generator (Project #27)**: 10-step mathematical color ramp generator with instant CSS custom properties and `tailwind.config.js` export.
- **Hardware Device Previewer (Project #26)**: Realistic bezel simulation across Mobile (375px), Tablet (680px), and Desktop (100%).
- **Multi-Stack Code Exporter (Project #30)**: Live code viewer for React + TypeScript, Vanilla CSS, and Tailwind CSS.
- **5 Dynamic Themes**: Midnight Dark, Clean Light, Cyberpunk Neon, Emerald Forest, and Sunset Violet.
- **Dedicated `/human` Community Hub**: Artisanal collective showcase using human vector SVG icons exclusively.
- **Automated Test Suite**: Node.js automated verification for resources, projects, and ecosystem integrations (`npm test`).
